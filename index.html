ブラウザだけで、
3D地球儀を飛び回る

3D地球儀を自分のコプターで自由に操縦できるフライト体験アプリです。世界の名所へワンタップで移動し、テイクオフしたらそのまま大空を飛び回れます。インストール不要、ブラウザですぐに遊べます。

🚁 アプリを起動する できることを見る

できること

選んで、飛んで、操る

🌍

世界の名所へワンタップ

富士山・エベレスト・グランドキャニオンなど9つのプリセット地点や、地名検索で行き先を選んでテイクオフできます。

🎮

直感的な操縦

WASDと矢印キーに加えて、右のスライダーやマウスホイールでも速度を直接調整できます。スマホはドラッグとボタンで操作可能です。

🌀

速度に連動する旋回

低速ではゆったりと、高速ではダイナミックに旋回できるので、操縦のメリハリを自然に感じられます。

🏙️

Googleフォトリアル3D(任意)

Google Maps PlatformのAPIキーを設定すると、実写のような3D地形・建物の上を飛行できます。キー無しでも無料の地図でそのまま遊べます。

🎵

BGM付きの没入感

飛行中はBGMが流れ、速度に合わせて音量とテンポが変化します。

📲

スマホを傾けて操縦

ジャイロセンサーでスマホを傾けるだけで視点と旋回を操作できる、一人称視点のチルト操作モードに対応しています(任意)。

💾

データは端末内に保存

Googleフォトリアル3D用のAPIキーは、お使いのブラウザ内(localStorage)にのみ保存されます。

📱

ホーム画面に追加(PWA)

スマホのホーム画面に追加すれば、アイコンをタップするだけでアプリのように起動できます。

使い方

Googleフォトリアル3Dを使わなければ、登録不要ですぐ遊べます

  1. 「アプリを起動する」を押すインストール不要、ブラウザですぐ開けます。
  2. 行き先を選ぶプリセット地点をタップするか、地名を検索して行き先を決めます。
  3. 「テイクオフ」を押す離陸前は地球儀をドラッグして自由に見渡せます。
  4. WASD・矢印キー・スライダーで操縦スマホの場合は画面ドラッグとボタンで操作します。
  5. (任意)Googleフォトリアル3Dを使う実写のような3D地形で飛びたい場合のみ、下の「APIキーの取得方法」を参考にキーを発行して貼り付けてください。

ホーム画面への追加方法

アイコンをタップするだけでアプリのように起動できます

📱 Android(Chrome)

  1. Chromeでこのアプリのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「アプリをインストール」または「ホーム画面に追加」をタップ
  4. 表示名を確認して「インストール」

🍎 iPhone(Safari)

  1. Safariでこのアプリのページを開く(他のブラウザ不可)
  2. 下部の共有アイコン(四角に上矢印)をタップ
  3. 「ホーム画面に追加」を選択
  4. 表示名を確認して右上の「追加」をタップ

Google Maps APIキーの取得方法(任意)

無料枠の範囲内なら、個人の利用では基本的に課金は発生しません

  1. Google Cloud Console でプロジェクトを作成console.cloud.google.com にアクセスし、Googleアカウントでログインして新しいプロジェクトを作成します。
  2. Map Tiles API を有効化する「APIとサービス」→「ライブラリ」で Map Tiles API を検索し、「有効にする」を押します。
  3. 請求先アカウントを登録する初回はクレジットカード等の登録が必要です。無料枠の範囲内であれば、個人利用では通常課金は発生しません。
  4. APIキーを発行する「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」を選択してキーを発行します。
  5. (推奨)キーを制限する発行したキーの編集画面で、API制限を Map Tiles API のみに絞ると安全です。
  6. アプリに貼り付けるアプリ起動画面の「Google フォトリアル3D」をONにし、表示された入力欄にキーを貼り付けてください。
料金の目安: 毎月一定額までの無料枠が用意されています。最新の料金・無料枠はGoogle Maps Platform公式ページでご確認ください。
